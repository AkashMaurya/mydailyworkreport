How enhancement works
  1. Click Enhance on any entry — raw title & description are sent to OpenRouter.
  2. System prompt rewrites to professional English & categorizes into 8 fixed categories; returns JSON {enhanced_title, enhanced_description, category}.
  3. Original is never overwritten; both versions stored. UI shows enhanced by default with toggle to raw.
  4. If API fails or key missing: clear error, original remains visible, app degrades gracefully.

Security notes

  • Passwords hashed with bcrypt before SQLite storage.
  • OpenRouter key encrypted with Fernet (key derived from FLASK_SECRET_KEY or explicit FERNET_KEY). Never in frontend, .env, or git.
  • Sessions expire after 8 hours (filesystem, httpOnly, SameSite=Lax).
  • All routes run locally; no external calls except OpenRouter on Enhance.
